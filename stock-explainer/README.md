# 自然语言智能选股与策略解释器

把“经营改善、估值合理、走势相对稳定”这类模糊表达，转成**可检查、可修改、可执行**的数据条件，用扶摇数据筛出候选股，并解释**为何入选、为何排除、条件变化的影响**。

## 快速启动（Python 3.9+，零第三方依赖）

```bash
cp .env.example .env      # 填入 FUYAO_API_KEY（可选 ANTHROPIC_API_KEY）
python3 server.py         # http://localhost:3000
python3 -m unittest discover -s tests -v
```

| 环境变量 | 说明 |
|---|---|
| `FUYAO_API_KEY` | 扶摇 Key（请求头 `X-api-key`）。**未配置 → 示例数据模式**，页面顶部和每个结果均明确标注“合成数据，非真实”。 |
| `ANTHROPIC_API_KEY` | 可选。配置后用 LLM 解析规则词典无法覆盖的描述；输出必须通过白名单校验，失败回退规则解析。 |
| `UNIVERSE` | 可选，逗号分隔的 thscode 列表，覆盖默认 40 只大中盘股票池。 |
| `PORT` / `FUYAO_BASE` / `LLM_MODEL` | 端口 / 扶摇地址 / LLM 型号。 |

部署：任意能跑 Python 的平台（Render/Railway/Fly/自有服务器）执行 `python3 server.py` 即可；在平台里设置环境变量，**不要把 Key 提交进仓库**（`.env`、`data/` 已在 `.gitignore`）。

## 产品流程

1. **说意图** → 解析为条件（指标 / 算子 / 阈值），每个模糊词给出“严格/标准/宽松”三档口径，默认标准。
2. **检查与修改**：启用/停用、改算子与阈值、增删条件；展示每个指标的数据口径；未能量化的表述会明示“未参与筛选”；冲突识别（同指标区间矛盾=硬冲突；“高成长×估值合理”等=软提示；“高弹性×走势稳定”=硬冲突）。
3. **筛选**：对股票池逐条评估，结果分 入选 / 排除 / 待定（数据缺失）。缺失策略可选：保守（默认，列为待定）或忽略缺失并标注“数据不完整”。
4. **解释**：每只股票展开显示每个条件的 要求 / 实际值 / 数据时点 / 来源接口与字段 / 通过与否；排除的股票给出“放宽到多少即可通过”。
5. **条件变化影响**：逐条去掉条件重算入选数变化与新增入选；列出“只差一项”的股票。
6. **后续动作**：勾选比较；历史回看（等权 vs 股票池基准，附前视偏差说明）；保存筛选；转为监控任务（以当前名单为基线，“立即检查”显示新进入/退出）。

## 职责边界（AI / 引擎 / 数据）

| 层 | 做什么 | 不做什么 |
|---|---|---|
| AI（可选 LLM + 规则词典） | 意图 → 条件 JSON；提出口径澄清问题 | 不选股、不取数、不判断涨跌；输出只能引用指标目录内的 key，否则丢弃 |
| 确定性引擎 `app/engine.py` | 条件评估、冲突/敏感性计算 | 无随机、无 AI；同输入同输出 |
| 数据层 `app/datasource.py` | 调扶摇接口，换算单位，标注时点/字段 | 不做筛选判断；失败/缺失原样上报，不补零、不静默 |

## 指标与口径（`app/catalog.py`）

PE(TTM)、PB(MRQ)：`valuations/snapshot`；营收/归母净利同比：`income-statements(quarterly)` 最新报告期 vs 去年同期；经营现金流：`cash-flow-statements`（元→亿元）；负债/总资产：`balance-sheets` 的 `total_debt/assets_total`；年化波动率、近120日最大回撤：`prices/historical` 前复权日线（≥60 根才计算）。

## 合规边界

不输出涨跌预测、收益承诺、直接买卖建议。命中“稳赚/保证收益/明天涨停/该不该买”等表述时拒绝生成并说明原因。结果文案为事实陈述（“满足/不满足条件”），不含“推荐”。页面底部常驻免责声明。

## 已知边界与未做事项

- **未能在本地验证真实扶摇响应**：开发时无 API Key，真实接口字段按官方文档编写，并用 mock 测试了 null、业务错误码、样本不足等分支；**请配置 Key 后先跑一遍并核对**。
- 估值接口单位、`total_debt` 是否为总负债以官方文档为准，已在页面口径中说明。
- 股票池为固定 40 只（可用 `UNIVERSE` 替换）；未实现全市场、指数/板块成分池（扶摇有相应接口，可在 `get_universe` 扩展）。
- 未接入 iFinD MCP（市场宽度/新闻/政策）；未做行业与市值条件；监控任务只在手动点击时检查，无定时推送。
- 历史回看不是严格回测（用当前条件回看过去，存在前视偏差）。
- 数据缓存 30 分钟（内存）；保存/监控存于本地 `data/*.json`，无用户体系。
