# 测试说明

运行：`python3 -m unittest discover -s tests -v`（18 项，全部通过，无需网络/Key）。

| 类别 | 用例 |
|---|---|
| 主链路 | 模糊词→条件+口径澄清；三档口径改变阈值；未量化表述被披露；引擎 通过/排除/缺失 与缺失策略；解释可追溯（实际值、时点、差距、放宽建议）；去掉条件的敏感性与“差一项”；示例数据端到端、确定性；历史回看 |
| 冲突 | 同指标区间矛盾（硬）；高弹性×走势稳定（硬）；高成长×估值合理（软） |
| 数据/接口异常 | 接口全部失败 → 条件标“缺失”，股票为“待定”，不当作正常；上游 null、去年同期≤0、K 线样本不足 → 各自给出原因；业务错误码(如 2001)不重试不静默 |
| 合规 | 收益承诺/涨跌预测/买卖建议被拦截且不产出条件；正常描述不误拦；LLM/用户输入的非法指标、算子、阈值被拒 |

手工验证（未自动化）：浏览器中“解析→改阈值→运行→展开明细→比较→回看→保存→监控检查”，截图见演示；真实 Key 下的数值核对需使用者执行（见 README 已知边界）。
